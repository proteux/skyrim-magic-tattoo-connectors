# Changelog

Version 0.3.22

New: Cast a spell — any load-order spell while the tier shows, hits as hard as the applier's own cast.
New: Cast an aura — same spells on targets in 1–50 m. Targets: Everyone / Allies / Enemies (default Allies); never the wearer. FnF at half strength
New: Faction reaction nearby — a living target in range matching Everyone / Allies / Enemies
New: Magicka Free / Paid by applier / Paid by wearer
New: Damage, aggro, and kill credit go to the recorded applier (follower casting coming "soon").


Version 0.2.1

Fix: effects apply again after the plugin was disabled for a session and re-enabled; leftover changes undo on the next load.
Fix: uninstall/reinstall saves where MTF kept calling a leftover empty plugin copy.
New: console reset for Shout recovery, Rested bonus, Facial mood, Night vision, No fall damage, and Magic aura: `setpqv MTF_Plugin_Skyrim ResetOnLoad 1`, then save and load.


Version 0.2.0

New: Magic aura — one of 80 Skyrim/Dawnguard/Dragonborn visuals MTF's Shader effect doesn't offer; restores after a load.


Version 0.1.0

New: First release — 18 conditions and 9 effects (stats, moon, darkness, season, holiday, bounty, hidden, crafting, diseased, kill/level/cast triggers, night vision, shout recovery, cure, rested, mood, calm, no fall damage, weather, experience).
